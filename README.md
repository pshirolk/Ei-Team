# Ei-Team
 
**Winner, Web Category — UVM Hackathon 2024 (Team 18)**
 
A web app built in a 7-hour hackathon to help UVM students get outdoors. The prompt was to build an app that solves an outdoors-related problem affecting UVM students.
 
## What it does
 
- **Weather forecasts** so students can check conditions before heading out
- **Event sign-ups** for outdoor activities, with capacity limits
- **User posts** so students can share plans and find people to join
